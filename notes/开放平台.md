# 开放平台：TsFullStack 账号体系对外输出

[[开放平台]]

目标：其他网站可以直接使用本站的账号体系做登录，登录授权与会话安全全部由本站承担。接入方只需实现标准 OAuth2 授权码流程，不重复实现注册/登录/会话管理。

## 接入应用注册表 OAuthClient [[oauth-client-registry]]

- 管理员可在后台注册接入应用：应用名、首页、回调地址列表（精确匹配，多个以换行分隔）
- 注册时生成 `clientId` 与 `clientSecret`（secret 仅创建时明文展示一次，库中只存 bcrypt 哈希）
- 应用可禁用/删除；禁用后 authorize 与 token 流程全部拒绝
- 实现见 [openPlatformApi.ts](apps/backend/src/api/appApi/openPlatformApi.ts)

## 授权码流程（authorization code）[[oauth-code-flow]]

- 接入方把用户浏览器重定向到本站 `/oauth/consent?client_id&redirect_uri&state&scope` 授权确认页
- 未登录用户先在本站登录（登录后回跳授权页）；已登录用户看到「应用 X 请求访问你的昵称/头像」确认页
- 用户确认后本站签发一次性授权码（10 分钟有效，KVStore 存储，原子消费防重放），浏览器带 `code&state` 重定向回接入方 `redirect_uri`
- 授权码必须绑定签发时的 clientId + redirectUri + userId；token 兑换时逐项校验
- 实现见 [consent.vue](apps/website-frontend/src/pages/oauth/consent.vue)、[openPlatform.ts](apps/backend/src/server/openPlatform.ts)

## Token 端点与用户信息 [[oauth-token-userinfo]]

- `POST /oauth/token`：`grant_type=authorization_code`（client_id + client_secret + code + redirect_uri + 可选 code_verifier）或 `grant_type=refresh_token` 换 `access_token`（Bearer，14 天）+ `refresh_token`（30 天）
- `GET /oauth/userinfo`：Bearer access_token 换用户信息（sub/nickname/avatar/email）；email 为伪邮箱时不下发
- `POST /oauth/revoke`（RFC 7009）：吊销 access/refresh token（接入方登出/解绑时调用）
- access_token/refresh_token 走 KVStore（TTL 自动过期）

## Refresh token 轮换 [[oauth-refresh-rotation]]

- 每次刷新旧 refresh_token 作废、发新对（轮换语义）；并发刷新只有一个成功
- refresh_token 绑定签发时的 clientId：换到别的 client 上使用视为泄露，立即作废并留安全日志
- 实现见 [service.ts](apps/backend/src/OpenPlatform/service.ts)

## PKCE（公开客户端） [[oauth-pkce]]

- authorize 阶段接入方可带 `code_challenge` + `code_challenge_method=S256`（确认页透传到 approve）
- token 兑换时必须回传合法 `code_verifier`（43~128 字符），恒定时间比较防 timing 泄露
- 未携带 challenge 的授权码不校验 PKCE（机密客户端已由 client_secret 保护）
- 实现见 [service.ts](apps/backend/src/OpenPlatform/service.ts)、[openPlatform.ts](apps/backend/src/server/openPlatform.ts)

## 安全约束 [[oauth-security]]

- redirect_uri 必须与注册列表精确匹配（防止授权码经开放重定向泄露）
- client_secret 只存 bcrypt 哈希；比对失败统一报 invalid_client，不区分「不存在/密码错」
- 授权码一次性：并发兑换只有一个成功（KVStore takeIfEqual）
- state 由接入方生成、本站原样回传，防 CSRF 的责任在接入方（文档中注明）
